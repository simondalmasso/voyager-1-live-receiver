# Evidence bundles

The listener creates deterministic ZIP evidence bundles with canonical JSON, fixed ZIP metadata, SHA-256 per-file hashes and tamper verification. Raw evidence is never rewritten by RFI transforms; masks/configuration are separate products. Secret-like material is rejected before packaging.

Browser downloads are reduced-product JSON bundles because Cloudflare never receives raw IQ by default. If no synthetic, recorded-authentic, or verified station product exists, the UI refuses to create an empty scientific-looking bundle and states what is missing. Hash manifests provide integrity; they are not presented as identity signatures.
