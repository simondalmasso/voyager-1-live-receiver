# SPICE trajectory

The checked-in small trajectory is a narrative visual path and is labeled `INTERPOLATED`; it is not an ephemeris. A production scientific trajectory should be regenerated from official NAIF Voyager SPK kernels plus generic kernels, recording URLs, SHA-256 hashes, coverage, frame, units, and control-point comparisons against Horizons. Kernels are not downloaded or committed automatically because redistribution terms and exact kernel set must be reviewed.
